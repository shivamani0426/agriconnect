# AgriConnect

Multi-tenant agricultural commerce platform. Day 1: farmer onboarding, FPO management, harvest approval and shared marketplace inventory. React + TypeScript + Supabase. WhatsApp and ONDC are deferred; no paid services.

Setup: configure VITE_SUPABASE_URL and VITE_SUPABASE_PUBLISHABLE_KEY from the dedicated AgriConnect project. Never use a service-role key in the browser. Apply the database migration before running the frontend.
