# ONDC local batch 04B–04D
Status: isolated local simulation, NOT ONDC-certified or network-connected.
- 04B: in-process request/ACK/signed callback harness, only /search enabled; all transaction routes fail closed. No server binding, external fetch, secrets, database mutations, payments, or registry enrolment.
- 04C: BLAKE2b-512 + Ed25519 with raw bytes, strict authorization parsing, TTL, local trust registry, buyer/URI binding, replay/conflict handling and bounded memory. Test keys generated per invocation, never persisted. Gateway signatures, live registry lookup, key rotation, persistent receipts/outbox, registry subscribe challenge and official interoperability vectors are future external-network requirements.
- 04D: adapter consumes the existing public.catalogue() column shape, but the CLI intentionally uses synthetic rows only. Explicit synthetic FPO/crop eligibility and city, INR paise conversion, one-kilogram SKU, stable IDs within price variants, read-only refresh, no farmer identifiers. Availability count 99 means in stock in this projection, not 99 kg; fractional stock below 1kg is excluded. No real FPO catalogue is published. SKU IDs include price because the current aggregate groups by price; persistent production item identity and price-version mapping are pending.
- Version 1.2.5 provisional local target; official RET10 profile/version and full JSON schema (including serviceability, fulfillment, locations, statutory fields, policies, taxation, quantity limits, and incremental refresh) must be validated before preprod. Local NACK codes intentionally LOCAL_* and not ONDC network error codes. No guarantee of conformance.
- Search supports a small documented subset: city std:080 or *, item descriptor name substring, explicit category Fruits and Vegetables, provider id. Unknown fields rejected. No callback URL is contacted.
- Test: npm run ondc:test. Demo: npm run ondc:demo -- Tomatoes. Full suite: npm test. Fixtures are fictional. No dependencies added.
- Sources: https://github.com/ONDC-Official/ONDC-RET-Specifications ; https://github.com/ONDC-Official/developer-docs/blob/main/registry/signing-verification.md ; https://github.com/ONDC-Official/.github/blob/main/profile/README.md ; https://github.com/ONDC-Official/v1.2.0-logs/issues/705 (older version example only; confirm current semantics).
- Next 04E–04G: external identity model, quote and checkout, transactional order mapping and lifecycle, using disposable database fixtures. No production activation until explicit approval and free eligibility confirmation.
