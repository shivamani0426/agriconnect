# Pipeline 03F — manager notification inbox
New pending farmer memberships, pending harvests and confirmed/cancelled orders automatically create one event in the same database transaction. Events begin at migration installation; existing work appears in live counts, not historical unread alerts. Only currently active managers of the relevant FPO can retrieve alerts; read state is individual per manager. Website: Notifications → Refresh notifications → Mark read. Linked manager WhatsApp test number: HI / ALERTS shows workload counts and up to 5 unread events, READ <reference> marks one read; no unsolicited sends, templates, cron, real payments or production phone. Reading never changes underlying workflow. If reply fails, send ALERTS again or use website. Temporary Meta access token may expire. Existing test allowlist and kill switch retained.
