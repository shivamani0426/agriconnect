# WhatsApp 05 combined upgrade candidate
**Not deployed; test-only.** The previous webhook remains the default. The new code is gated by WA_V2_ENABLED=true AND requires the proposed SQL schema. Do not set the flag on the existing live function before a migration, review and acceptance. No new services, external AI, templates or paid resources.
- 05A: transactionally commit command and reply; separate claim/attempt token, at most three attempts on explicit 429 rejection using Meta redelivery (no scheduler or guaranteed retry). Never retry uncertain send. Old receipts still dedupe. Reply expires after 2 minutes; cleanup is bounded opportunistic global cleanup on signed inbound messages; linked reply records are deleted on unlink, while dedupe tombstones remain. Scheduled idle-period purge and retention policy remain open. Newer commands supersede pending older replies. User RECOVER reads recent state, never replays mutation. A crashed sending attempt is uncertain; no automatic resend.
- 05B/C: aggregate provider acceptance, monotonic delivery callbacks, last-day rate-limit/token error observations and send latency; no actual proactive token introspection or alert scheduler. Callback arriving before accepted ID persistence can be missed. No performance claims about production.
- 05D: QUICK interactive role-specific lists, opaque one-use menu token. Old numeric guide/confirmation buttons remain. Quick-list titles and prompt in four languages; other new summaries and commands remain English, translated shortcut examples limited. 05E: exact natural-language harvest sentence preview for a farmer with one approved FPO, explicit read aliases. 05F: existing language selection and context preserved; exact native-script greetings choose an initial language without overwriting a saved preference; RECOVER reads status; no general language autodetection or resumable drafts.
- 05G/H: signed, allowlisted audio/image receive fallback only; no media fetch, storage, transcription, photo upload or AI inference. Users can dictate via keyboard or upload photos through website. Actual media feature needs cost/privacy/consent review and testing.
- 05I: farmer simulated earnings and harvest summary. 05J: SEARCH <crop>, ADD <index> <kg>, CART, CHECKOUT CART, CART CONFIRM <uuid>, CLEAR CART; one FPO, eight items, no reservation before confirm, shared SQL checkout, revalidates stock/price. No real payment. 05K: ORDERS [page], ORDER <uuid> across own channels; latest WA TRACK still supported. 05L: manager's active-FPO aggregate report.
- 05M/N/O: offline transport concurrency fixture (100 duplicate events), SQL transaction/security checks and full regression CI; real concurrent database stress test, Meta handset acceptance, global retention cleanup, operational monitoring, and final audit still pending. No changes to UI/ONDC or dependencies.
