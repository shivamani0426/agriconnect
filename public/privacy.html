Privacy policy

AgriConnect is a demonstration agricultural commerce platform connecting farmers, Farmer Producer Organisations (FPOs), and customers. This policy describes the current website and its WhatsApp test integration, operated by the AgriConnect project maintainers.

The current platform is for testing. Payments, refunds, settlements and delivery workflows are simulated. Do not enter actual payment credentials or sensitive personal information in demo orders.

1. Information we process

  • Account information: email address, display name, authentication identifiers and permanent account role. Google sign-in uses Google's authentication service; email/password sign-in uses Supabase Auth.
  • Farm and organisation information: FPO name and location, membership requests and approvals, crop names, quantities, harvest dates, crop photos, grades and prices.
  • Orders and delivery information: selected produce, quantities, demo delivery address, order status, stock allocations and simulated settlement amounts.
  • WhatsApp testing: the verified test recipient phone number, incoming message content and message identifiers are processed to check authorization and respond to supported test greetings. The webhook receipt table stores a hash of the message identifier, a processing status and a timestamp, not the raw message text or sender number. Meta and hosting infrastructure may process or retain messages and technical request logs separately.
  • Technical information: session data in browser storage and service logs used for authentication, security, operation and troubleshooting.

2. How we use information

We use these records to authenticate users, enforce account roles and FPO membership permissions, review harvests, display available produce, reserve inventory, track demo orders, calculate simulated payouts, operate test messaging and diagnose errors. We do not use WhatsApp messages for advertising or sell user information.

3. Who can access information

Access is limited by account role, ownership and FPO membership. Public marketplace information includes published FPO and produce listings, grades, prices and available quantities. Authorized FPO managers can review their organisation's membership and harvest information, crop photos and relevant orders and delivery addresses. Farmers can view their own harvests and allocations; customers can view their own orders. Project maintainers and service providers may access data as necessary to operate and secure the service.

4. Service providers and storage

Supabase provides authentication, database, private photo storage and Edge Functions. Render hosts the website. Google provides optional sign-in. Meta provides WhatsApp Cloud API test messaging. These services may process data on infrastructure outside your country. Their respective privacy practices apply to their own processing. See Supabase, Render, Google and WhatsApp.

5. WhatsApp test integration

Only explicitly approved test recipients are supported. Incoming webhook requests are checked for a valid Meta signature and the configured test account and phone number. The current integration responds to supported greetings when enabled; it does not create real WhatsApp orders or link WhatsApp identities to user accounts. Website WhatsApp and ONDC order options are simulations. We will update this policy before enabling new data uses or live ordering features.

6. Security and retention

We use HTTPS, role-based database access, restricted photo storage, server-side secrets, and webhook signature verification to reduce unauthorized access. No system is completely secure. Test records may remain until removed by project maintainers; there is not currently an automatic deletion schedule. Service providers may retain logs according to their own settings and requirements.

7. Access, correction and deletion requests

You can request access to, correction of, or deletion of your account information and associated data, or request removal of your phone number from the WhatsApp test list. Self-service account deletion is not currently available. Project maintainers need to verify your identity and assess records that must be retained for other users' transactions, security or applicable obligations. We will not ask you to post passwords, access tokens or verification codes.

To contact the project maintainers, use the AgriConnect project contact page to request a private contact channel for a privacy or deletion request. The issue tracker is public: do not include your email address, phone number, order details or other personal information there. Once a private channel is established, the maintainers can verify and handle your request.

8. Changes to this policy

We may update this policy as AgriConnect develops. The last-updated date identifies the current version. Review this page before participating in new testing features.
